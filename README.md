# Quest3TriggerUI

为 **Virt-A-Mate 1.22.0.12** 在 **Quest 3（及 OpenVR/PCVR）** 下提供完整 VR 原生交互的 BepInEx 插件：VR 虚拟键盘 + 拼音输入法、径向快捷菜单、VR 预设/文件浏览器、原生对话框接管、包管理器封禁与卡顿缓解、物理降载档位与头发手动调试等。

## 功能一览

- **VR 虚拟键盘**：右手食指扳机+握把组合键呼出；世界空间 UI，可直接在 VR 里打字
- **离线中文拼音输入法**：rime-ice/雾凇拼音词典本地化——全拼、首字母简拼、模糊/前缀联想、词组补全、分次提交整句、**用户词频记忆**（`[IME] Learning` 开关）
- **径向快捷菜单**：右手食指长按呼出，物理降载/待机/重置等快捷动作
- **VR 预设浏览器**：接管 VaM 原生皮肤/外观/头发/服装/替换等全部文件对话框，var 包内容合并视图、启动预热防首开卡顿；标签页**视图状态持久化**（同地址标签共存、滚动/搜索/排序重开保持）；右上角**目标人物下拉**——预设可直接改加载到场景里其他 Person（含被关闭的）
- **预设部件化**：服装/皮肤/头发/眼睛四区块独立存取——人物预设可当部件库直接"拆用"（只换发型/只换肤/只换装/只换眼），当前部件也可写回任意本地人物预设；含 VaM 原生没有的眼睛预设系统（irises/sclera/lacrimals + 原生缩略图）
- **UIAssist 预设坞/收藏栏**：服装编辑器左右双栏缩略图即点即换；左侧预设坞五标签（替换/外观/发型/服装/皮肤）「新增」按标签开对应目录批量收藏；缩略图**拖拽重排**、跨标签拖放收藏、**连续滚动条浏览**（拖拽中推摇杆滚动，光标贴栏顶/底自动滚）；左坞三模式直切——服装收藏/预设坞/**场景收藏**（BrowserAssist 场景图长按拖入，标签分组，一键保存当前场景）
- **VR 拍照机位**：多机位 VR 相机拍摄，缩略图、场景持久化、前后跳切
- **音频跟随**：VaM VR 音频自动跟随 Windows 默认输出设备切换，无需手动改路由
- **场景加载加速**：headless 菜单期预热（形变库/编目初始化 + 原子克隆池），加载窗口内选择器重建合并，大场景冷载 ~190s→~110-130s
- **包管理器封禁**：默认屏蔽原生包管理器入口（VaM 包扫描+缩略图解码是主要卡顿源），`[Browser] BlockPackageManager` 可关
- **物理降载档位 + 手动头发调试**：快捷降载，或逐片选中头发实时调 curl/density/模拟/碰撞
- **热重载架构**：HotLoader 常驻 + payload 字节加载，替换 payload 文件即热更新，无需重启 VaM
- **资源生命周期管理**：贴图解码在途字节预算（随可用内存/提交余量自动收紧）、同基底衣发跨预设复用、孤儿贴图来源追踪驱逐、预设清理事务化——连续换装不再把显存和提交一步步顶死

### v4.6.287~v4.6.293 —— 换人清扫免付、场景收藏栏、播放兼容扩展（2026-09-29）

本组主线是换人路径的内存治理（实测取证后精准摘掉近零回收的全局清扫），外加一个完整的场景收藏栏和一批剧情场景播放兼容扩展：

- **换人不再付 9 秒 UUA 清扫**：实测换人后由 preset 路径提交的 `Resources.UnloadUnusedAssets` 要花 8.5~9.1 秒主线程，实际只回收 ≤16MiB 内存、0 VRAM——现在按调用链精准降级这一类清扫（只杀 PresetSweepGate 提交且不属于 janitor/待机/场景加载的路径），并给等待方返回已完成的 operation 不阻塞协程。默认开启，`Diagnostics/UuaGate` 可关
- **换人 GC 移交空闲看门狗**：换人路径的全量 GC 不再在加载窗内硬跑，交给空闲期触发（托管堆接近上限或高于加载线时点火），延期有界——同次换人的 2.5~3GB 托管垃圾照收，只是不在你最卡的时候收
- **.var 流读加速**：var 包内条目读取加 64KiB 缓冲（EntryStreamBuffer，修掉 EOF seek 崩溃）——实测一组人物条目 8737ms→144ms；场景冷载的二进制读同样走缓冲
- **服装编辑器提速**：RefreshACE 同帧合并——开编辑器时 292 次逐行重刷收成 1 次；重开编辑器保留格子不再重建
- **场景收藏栏**：服装编辑器左侧合并坞新增「场 景」模式（服装/预设/场景三模式标签条直切，统一布局）；长按 BrowserAssist 场景缩略图可直接拖入收藏（落在坞上即收，自动切到场景模式）；标签可增删改名、缩略图拖放复制；「保存」把当前场景落到收藏（覆盖/换缩略图，不开浏览器）；点名字只改收藏别名不动文件；修复重启后 var 包内场景缩略图不加载
- **剧情场景播放兼容扩展**：命名段按钮链容忍 Stop And Reset 等随行调用（LDR.Staying_Late 5 段恢复）；纯 `Play Segment N` 链也认作阶段（vamsoy.spycam 22 段接管）；多命名组并存时接管唯一最大组（The Flight Attendant：DockedUI 12 姿势按钮 vs 语言模式切换组）
- **「清除黑屏」快捷动作**：故事场景过场淡入丢失（VAMOverlays 黑幕没收回）时一键广播 Start Fade In 恢复画面
- **场景内加载后编辑器报错修复**：加载期不再回放 ACE 刷新队列（消灭死组件 NRE）；视锥前方无人时服装编辑器回退取全场最近 Person
- **一键缓存孤儿清理**：VaM 磁盘缓存目录（D:\vamcache）孤儿清理入口
- 其余为内部诊断项：UUA 卸载量普查、UnloadCoverageProbe、ItemBuildProbe 等，不改变日常行为

### v4.6.267~v4.6.286 —— 预设坞保存修复、纹理缓存自动转 BC7、换人 GC 收益门（2026-09-28)

本组主线是三块：预设坞保存链路重写（覆盖终于写到对的文件）、贴图磁盘缓存自动转 BC7（体积/显存约省 3/4）、以及换人与热载路径上的一串卡顿治理：

- **预设坞「覆盖」修复**：此前覆盖可能把序列化结果写到 `Preset_` 前缀副本而原文件不动、或把编辑器的过期状态写进文件（换衣后覆盖再加载还是旧衣服）。现在保存前强制刷新预设管理器的 storable 列表、直采原生序列化产物、校验文件里的服装清单与角色实时穿着一致才落盘，原子写回收藏指向的精确路径——不一致直接报错拒写，不再静默写旧内容
- **预设拍照回到 VaM 原生瞄准截图**（更正上一条说明）：上版的"直接抓帧"会把 UI 拍进缩略图，已恢复为原生"瞄头按 select"流程；「覆盖」只更新 .vap 不动缩略图，要换图用「拍照」
- **保存模式互斥修复**：「保存」状态下点「读取/新增」后三个保存按钮永久残留的 bug 已修——保存会话与读取/新增/删除/切标签完全互斥进出
- **预设坞底部行缩略图修复**：收藏很多时切换标签来回后，从没解码过的底部行永远空白——恢复 parked 格子时漏回填解码队列，已对齐服装收藏栏的行为补上
- **纹理缓存自动转 BC7**：新进 VaM 纹理磁盘缓存的 RGBA32/RGB24 图在空闲时后台转 BC7（字节约 1/4），退出游戏后剩余队列走隐藏批处理；存量缓存可用配套工具全量转换（本机实测 87.36→56.70GiB）；BC4/BC5/BC6H/BC7 统一走精确准入。需要 texconv.exe（可选依赖，见安装说明）
- **内存压力 GC 收益门**：实测一次全量 GC ~5.6s 只回收 0.5GB 还把整个堆拉回工作集——现在预估收益不达标时不再白付这次停顿，改由空闲期/时间上限通道消化
- **服装编辑器提速**：刷新列表里每行一次的 N² 次对象比较改线性扫描，实测单趟 800ms→285ms
- **热载与换人路径治理**：payload 换代补齐 9 组此前漏挂的清理（解码池/孤儿清扫/探针），热载内存尖峰收窄；重载同外观零变化事务连 GC 判断都跳过；孤儿贴图清扫切片化，误伤的克隆体腿默认关闭（实测 17.7s→1.1s）
- 其余为内部诊断项：人物加载全链路区间计时框架、活集普查/堆探针等，用于定位长帧与内存构成，不改变日常行为

### v4.6.262~v4.6.266 —— 换人免清扫、预设坞改造与冷图预热（2026-09-26)

本组更新的主线是「换人不再白付 11~25 秒全局资源清扫」，外加预设收藏栏的一轮交互升级和冷图预热：

- **换人跳过 UUA 清扫**：人物预设事务前后对照资源账本，旧角色的资源全部被证明有主或已销毁时，跳过当次 `Resources.UnloadUnusedAssets()` 全局扫描（之前每趟换人固定 11~25 秒卡死）。拿不准的漏网资产按预算记账，攒够上限或空闲 60 秒时后台补扫；扫后仍存活的资产（第三方/原生缓存引用）转正为「幸存者」不再重复计债
- **重复加载同人物零清扫**：重载未变化的人物预设不触发 UUA 也不补 GC——自换完全无卡顿
- **预设坞交互升级**：切标签整栏清空重播加载动画，不再新旧缩略图混显；新增「对象」行显示当前读取目标角色（自动取视线最近的女性，可点开列表手动锁定，男性不出现）；保存对话框开着期间，点格子缩略图直接覆盖保存该预设（可现场重拍缩略图）、点名字条可就地改名；开着浏览器时点标签，浏览器跟着切到对应目录
- **保存拍照修复**：修复保存预设时第一次拍照被系统吃掉的问题——不再走 VaM 的瞄准截图模式，改为直接抓取当前画面生成缩略图
- **冷预设一键预热**：预设坞新增「预热」按钮，为「人物」标签下全部收藏预设预先生成贴图磁盘缓存（走 VaM 原生缓存格式与目录），之后首次加载这些人物不再付解码成本；已缓存的自动跳过
- **编辑器首开不卡**：左右收藏栏改为分帧填充（每帧预算 2 毫秒），服装编辑器打开不再有格子爆发式创建的大卡顿；缩略图悬停放大阈值定为 1 秒

## 构建

需要本机 VaM 1.22.0.12 安装（引用 `VaM_Data\Managed` 下的 Assembly-CSharp / UnityEngine 等）与 BepInEx 5.x 引用集。参照 `tools/build/build.example.rsp` 把 `F:\vam1.22.0.12` 路径替换为本机路径，然后：

```
csc.exe -noconfig @build.rsp
```

产出 payload dll 用 `src/PUBLISH_HOT_UPDATE.ps1` 发布到
`BepInEx\plugins\Quest3TriggerUI\Quest3TriggerUI.payload.dll.disabled` 即热载生效。

> ⚠️ **热载约定**：每次构建的 `/out` 程序集名必须唯一（如 `Quest3TriggerUI_pHHMMSS.dll`）。同名程序集字节加载时，方法内对其他类型的引用会绑定到首个同名程序集，导致"改了代码运行无反应"。
