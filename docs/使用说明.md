# Quest 3 Trigger UI v4.6.196 使用说明

VR 集成工具集：径向快捷菜单、虚拟键盘、手柄交互增强、
录制、待机降载等。先读 `安装说明.txt` 确认适用条件与依赖。

---

## 一、基础手柄操作

| 操作 | 效果 |
|---|---|
| 右手食指 **长按**（约 0.35s） | 弹出径向快捷菜单（披萨圆盘） |
| 左手食指点击 | UI 点击 / 菜单选择 |
| 右手食指按住滑条 | 直接拖滑条（不用开菜单） |
| 右手食指 + 右握把 **轻点** | 显示 / 隐藏虚拟键盘 |
| **双手握把轻点** | 键盘/面板重新居中 |
| 右握把 **长按** | Grab（抓取，VaM 原生） |
| 右摇杆上下 | Embody 状态下的视角俯仰 |
| 右握把按住 + 右摇杆上下 | 非 Embody 状态的视角俯仰 |

径向菜单结构：每个母按钮是一块扇形，**点击**执行主功能，
**悬停**会在母按钮外圈弹出它的子功能扇形。
菜单正中心按钮切换"固定模式"：开启后可把常用功能
拖到外圈固定成磁贴，磁贴可拖动排序、可删除。

## 二、径向菜单功能一览

### Embody
- **点击**：对面前最近的男性角色进入/退出 Embody。
- **子菜单**：导航复位（视角/导航状态恢复）。
- 需要 AcidBubbles Embody 插件包；未安装时按钮无效并写日志。

### 脱衣
- 打开 UIAssist 服装编辑器（自动选中面前最近的 Person）。
- 需要 UIAssist 插件。编辑器内附本插件的**预设坞/收藏栏/锁定栏/
  禁用栏**，右上角「隐藏/显示」按钮只收起编辑器主体（四栏保留）；
  右 Grip+右摇杆水平可环绕用户旋转面板群：
  - **左侧预设坞**：竖排五标签「替换/外观/发型/服装/皮肤」，
    点缩略图=把该预设加载/替换到当前人物对应区块；「＋新增」
    打开预设浏览器到该标签对应目录（替换/外观→Appearance、
    发型→Hair、服装→Clothing、皮肤→Skin），点浏览器里的
    预设即收藏进当前标签，浏览器保持打开可批量收。
  - **拖拽**：长按缩略图出 ghost，栏内拖动重排；栏体为**连续滚动
    条**浏览（滚轮/右摇杆/拖条均可），拖拽中推摇杆滚动、光标贴
    栏顶或栏底自动滚；拖到其他标签=跨栏收藏；左右两栏同一套
    拖放逻辑。
  - 收藏：把当前服装连同**预设与物理参数快照**一起收藏，
    下次点击收藏项直接恢复整套状态。收藏全局共享。
  - 锁定 / 禁用：按角色分别记录，锁定与禁用互斥。

### 录制
- VR 单眼录制（含系统混音），输出 MKV。
- 设置面板可选：缩放倍率（分辨率）、帧率、码率、编码器
  （H.264 / HEVC / AV1，均 NVENC）。
- **需要 NVIDIA 显卡 + ffmpeg**（见安装说明的路径配置）。

### 人物
- **点击**：直接跳转 VaM 原生的最近角色控制面板（Edit 模式）。
- **子菜单**：
  - 替换：最近女性角色的完整人物预设（含服装的精确回放）
  - 服装：浏览人物预设→**只提取该预设的服装**穿到当前角色，
    形变/头发/皮肤不动；悬停出第三环"保存"=把当前服装写回所选人物预设
  - 外观：点击打开外观预设浏览（保留当前服装）；
    悬停出第三环"保存"：把当前角色外观预设存为 .vap
  - 皮肤：统一加载——选皮肤预设=直接应用，选人物预设=只提取皮肤；
    悬停出第三环"保存"：新名建皮肤预设/选人物预设=只写回皮肤段
  - 头发：统一加载——选头发预设=直接应用，选人物预设=只提取发型；
    悬停出第三环"保存"：新名建发型预设/选人物预设=只写回发型段
  - 眼睛：自建眼睛预设库（irises/sclera/lacrimals，VaM 原生无此功能）；
    选人物预设=只提取眼睛；悬停出第三环"保存"：建眼睛预设+原生缩略图/
    选人物预设=只写回眼睛段
- 提取/写回均点对点内存操作，不产生链接文件；VAR 包内预设只读拒写
- 保存时浏览器可在文件名栏输入新名字（无 .vap 自动补）

### 灯光
- 打开 LightLinker 控制面板（切 Edit 模式并展开主 HUD）。
- LightLinker 未加载时会**自动懒加载进 Session Plugins**；
  在 .var 包里的用户改 `[Paths] LightLinkerUrl` 指向包内路径。
- 面板附带"恢复场景原始灯光"：按场景存档还原灯光原子。

### 表情
- **子菜单**：表情初始化 → 各表情项。SevenSeason 表情库，
  非破坏性预载/播放，每条表情独立 Timeline，可叠加混合，
  关闭后恢复舌头基线。
- **需要 AcidBubbles.Timeline 287+**（第三方插件，需自装）；
  表情靠 morph 驱动，42 个非内置 morph 分散在 AshAuryn、
  CheesyFX、SPQR 等 morph 包中，需自行提取合并到 VaM 根目录。

### 播放
- Timeline 播放控制：**子菜单**含初始化、上一个/下一个
  level、上一个/下一个 pose、播放/暂停等。

### DLSS
- VamDlssNr 插件的快捷开关：SR/NR 启用、强度/色调/结构参数。
- 直接读写 VamDlssNr 自己的配置项（与 F10 面板同源），
  未装该插件时无效。

### 物理
- 给最近角色应用物理插件包（BetterBends / OrificeDynamics
  等，需对应 .var 已安装）。

### 物理降载
- **子菜单**三档：关闭 / 均衡 / 激进。
- 逐件自适应缩放：头发密度/细节按比例降（本来就很低的
  项跳过），布料按粒子数分级——小件（如首饰）直接关模拟，
  大件降迭代。**不冻结、无状态跳变**，关闭档或热重载
  时全部还原。已实测确认不影响帧率的项才进预设。
- 细调参数见配置 `[PhysicsBudget]` 段。

### 优化内存
- 触发 VaM 自带 MemoryOptimizer 的优化流程。
- **后台自动回收（默认开）**：换预设时同基底衣发直接复用，
  解码在途字节有预算上限，失效请求解码前淘汰，孤儿贴图
  按来源追踪驱逐，清理事务等加载尾部落地后才结算。配置在
  `[TextureLoading]` / `[Wardrobe]` 段，全部可关。

### 刷新VAR
- **子菜单**：增量刷新（默认主功能）/ 完整扫描。
- 增量刷新监听 AddonPackages 变更队列，只重扫变动的包，
  并同步 BrowserAssist（如已安装）。

### 待机/恢复
- **点击**进入待机：相机切纯黑屏、暂停动画/物理/音频、
  主线程降到约 8 FPS、冻结头发/布料 GPU 模拟、纹理降到
  1/8 分辨率、关阴影池/AA/像素灯、清理游离资产。
- **再点恢复**：全部状态按进入时的快照还原，纹理异步
  上传通道临时拉满以加速恢复。场景和 VAR 全程驻留，
  不读盘、不重扫包。
- 用途：离开 VR 时把 GPU/CPU 占用压到接近零，回来秒级恢复。

## 三、虚拟键盘

- 右手食指 + 右握把轻点召唤；世界坐标悬浮面板，
  标题栏按住可拖动，双手握把轻点重新居中。
- 完整键盘 + 表情快捷区 + 眼皮开合度滑条（作用于
  最近女性角色）+ 临时快捷键模式。
- 输入走 Unity Input 桥写入 VaM 窗口，不依赖桌面焦点。

### 内置中文输入法（拼音引擎）

VR 内自带完整拼音输入法，**不需要桌面输入法**、不依赖
VaM 窗口前台、离线可用：

- **词库**：rime-ice 雾凇拼音（华宇野风/清华THUOCL/腾讯
  词向量合成，约 79 万全拼键 + 29 万简拼键 + 56 万模糊键），
  简体词条按真实词频排序，游戏/网络新词基本覆盖
  （雷电将军、神里绫华这类词直接出）。
- **打字**：字母进拼音组合，键盘左侧竖排候选栏实时出词。
  支持简拼（`ldjj`→雷电将军）、模糊音
  （z/zh、c/ch、s/sh、n/l、f/h、前后鼻音等 11 组）、
  长句自动分词、前缀联想（输一半就出整词）、
  部分提交续组（长句里选中前段词，余下字母继续组）。
- **键位**：数字 1-9 或点候选词选字；空格=首选；
  回车=原字母上屏；Esc=清组合；退格删尾字母；
  PgUp/PgDn 或 - /= 翻页；标点=提交首选+标点。
- **中/英切换**：键盘"中/英"按钮或 **Shift 轻拍**
  （按下即松、期间不碰别的键）；英文模式字母直输。
- **词频记忆**：选过的词/词组自动进用户词典——全拼、
  简拼、甚至只打前几个字母都能召回（学过"雷电将军"后
  `ld`、`leidian`、`ldjj` 都会优先出它）；同一键下越常
  用越靠前。整句分次提交的词组会作为整词记住。
  记忆存于 `BepInEx/config/Quest3TriggerUI.pinyin-user.txt`，
  换机随 cfg 迁移；`[IME] Learning = false` 可关。
- 词典为插件目录下 4 个 pinyin_*.txt（共约 48MB，
  后台加载不占启动时间）。

## 四、VR 预设浏览器（接管所有文件框）

自研世界空间文件面板，**默认接管 VaM 全部原生文件浏览框**
（含径向菜单保存/加载、UIAssist 服装保存/加载、以及
第三方插件调起的原生对话框；配置 `[Browser] TakeoverNative`
可关，关闭后回到原生框）。打开加载/保存入口时若已有
同类别标签页，会直接跳转到该标签（子目录优先）。

- **标签页**：顶部多标签，全局共享——任何地方打开同类
  目录都复用既有标签；标签跨会话记忆，最多 12 个；
  **视图状态随标签持久化**——每个标签各自的滚动位置、
  搜索词、排序方式在切换人物/重开浏览器后原样恢复，
  同地址标签页也各自独立保留。
- **目标人物下拉**：加载类对话框头栏最右显示
  「人物: <uid>」，点开列出场景全部 Person（含被关闭
  /隐藏的），选中后本次加载改投到该人物；保存/选目录
  类对话框不显示。
- **左侧栏**：可折叠。收藏夹（＋收藏当前目录、✕移除，
  跨会话保存）+ 懒展开目录树（▸/▾ 逐级展开，点当前行
  折叠，当前目录自动滚动居中，⟳ 全量刷新）。
- **文件区**：.vap 卡片带同目录伴生 .jpg 缩略图；
  路径栏、上一级、搜索过滤、名称/时间排序、新建文件夹、
  重命名、删除。
- **多选与批量**：空白处拖拽=框选；批量删除、批量移动、
  批量复制到指定目录（伴生 .jpg 随文件一起处理）。
- **拖拽移动**：按住卡片拖到目录卡片/树节点/收藏项
  即移动，ghost 标签跟手显示目标名。
- **保存模式**：文件名栏可输新名（无 .vap 自动补），
  选中已存在文件=覆盖；按类别记忆最近保存目录
  （外观/皮肤/头发/服装各自独立）。

## 五、其他细节

- **VR 光标**：射线指向的 UI 上显示发光圆环光标
  （`[GlobalCursor]` 可关）。
- **触觉反馈**：菜单悬停/确认等操作有短震动
  （`[Haptics]` 可调强度或关闭）。
- **后台运行**：插件强制 `runInBackground`，VaM 窗口
  失焦时游戏循环不暂停（串流链路需要持续出帧）。
- **日志**：`BepInEx/LogOutput.log` 中前缀
  `Quest 3 Trigger UI`；载荷热更新会打印
  `Hot-reloaded ... SHA256=...`。
- **热更新**：运行时替换同目录的
  `Quest3TriggerUI.payload.dll.disabled` 文件，
  HotLoader 约 1 秒内自动换载，无需重启。

## 六、常见问题

**Q：菜单按钮点了没反应？**
看 `BepInEx/LogOutput.log`——多半是缺可选依赖
（Embody/UIAssist/VamDlssNr/ffmpeg 等），日志里会写明。

**Q：录制按钮报错？**
确认 ffmpeg 路径配置正确且带 NVENC；确认是 NVIDIA 显卡。
录制中游戏卡顿属正常（GPU 读回+编码占带宽）。

**Q：预设浏览框打开的目录不对？**
改配置 `[Paths]` 段对应项（相对 VaM 安装目录）。

**Q：换了机器收藏还在吗？**
收藏/锁定/禁用数据在 `BepInEx/config/` 下的
`Quest3TriggerUI.*` 文件里，复制过去即可。
注意锁定/禁用按角色 uid 记录，别的机器上同名角色
才算同一人。
